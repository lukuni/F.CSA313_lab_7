# BUG-07: /api/books буруу JSON биетэй POST хүсэлтэд 400 биш 200 OK буцаана

Орчин:  Уншлагын жагсаалт v2.0, Safari 26.1, macOS 26.1, 2026-10-20
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Терминалд `node app.js` ажиллуулна.
2. Өөр терминалд дараах командыг ажиллуулна:
   ```bash
   curl -i -X POST localhost:3000/api/books -H "Content-Type: application/json" -d '{bad json'
   ```
3. Гаралтын эхний статус мөр болон биеийг харна.

Хүлээгдэж байсан: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»
Бодит үр дүн:     `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}` — алдаа мэдэгдэхгүй, амжилттай мэт хариулна.

Ноцтой байдал: Major — API клиент буруу хүсэлтээ амжилттай гэж ойлгоно; UI-ийн шалгалтыг тойрон буруу өгөгдөл оруулах боломж нээлттэй.
